# ManageMoney

自分の資産と収支をまとめて管理する Web アプリです。PC でもスマホのブラウザでも使えます。ログインは不要です。

- **資産**：銀行・現金・証券・暗号資産・クレジットカードなどの口座ごとの残高と総資産
- **収支（家計簿）**：収入・支出・口座間の振替を記録。月ごとの一覧とカテゴリ別の円グラフ
- **予算・目標**：月の予算（全体／カテゴリ別）の使用状況、貯金目標の進捗と毎月の必要額
- **クイック入力**：ホームの「支出」「収入」とよく使うカテゴリのボタンから、すぐ金額を入力できる
- **レシート読み取り**：レシートの写真から合計額・日付・店名・カテゴリを読み取って入力欄に入れる（ブラウザ内で処理）
- **バックアップ**：データを JSON ファイルに書き出し、別の端末やブラウザで復元できる

## データの保存について（大事）

データは **開いているブラウザの中（localStorage）だけ** に保存されます。サーバーには送られません。

- PC とスマホ、別のブラウザの間ではデータは共有されません
- ブラウザの「閲覧データを削除」やシークレットモードの終了で消えます
- 「設定」→「データのバックアップ」から **ときどき書き出しておいてください**。機種変更や別の端末に移すときは、そのファイルを「バックアップから復元」で読み込みます

## 使い方

```sh
npm install
npm run web      # http://localhost:8081 で開く（レシート読み取り用のファイルを public/ocr にコピーしてから起動）
```

### Vercel で公開する

1. Vercel でこの GitHub リポジトリをインポート（`vercel.json` にビルド設定があるので、設定や環境変数は不要）
2. 以後は push するたびに自動でデプロイされます

## 使い方のポイント

- 取引に口座を指定すると、その口座の残高が自動で増減します（編集・削除しても正しく戻ります）
- 証券・暗号資産など値動きがあるものは、「資産」タブで口座をタップして評価額を書き換えてください
- クレジットカードは残高をマイナス（未払い額）で管理し、引き落とし時に「振替（銀行 → カード）」を記録すると残高が 0 に戻ります
- 予算は「全体」と「カテゴリ別」を設定できます。ホームの「今月あと○円使えます」は、全体予算があればそれを、なければカテゴリ予算の合計を使います
- ホームのクイック入力に出すカテゴリは「設定」タブで選べます（最大 4 つ）

### レシート読み取り

ホームの「📷 レシート」から写真を撮る（または画像を選ぶ）と、合計額・日付・店名（メモ）・カテゴリを読み取って入力画面に入れます。**保存する前に内容を確認してください。**

- 文字認識（[Tesseract.js](https://github.com/naptha/tesseract.js)）は **ブラウザの中だけ** で動き、画像は外部に送信されません
- 初回だけ認識用のデータ（約 6MB）を読み込みます。2 回目以降はブラウザのキャッシュから読むので速くなります
- うまく読むコツ：明るい場所で、レシート全体を真上から、影や折り目が入らないように撮る。感熱紙が薄くなったものや手書きは苦手です
- 合計は「合計」「お買上計」「お会計」などの行から取り、「お預り」「お釣り」「税」の行は無視します。カテゴリは店名やキーワード（コンビニ・スーパー → 食費、ドラッグストア → 日用品 など）から推測します
- 読み取った生の文字は「読み取った文字を見る」で確認できます

## 開発

```sh
npm test            # 単体テスト（集計・残高計算・データ操作・バックアップ・レシート解析）
npm run typecheck   # 型チェック
npm run lint        # ESLint
npm run build       # dist/ に Web 版を出力
```

- 技術構成：Expo SDK 57 / Expo Router / React Native Web / TypeScript（`expo export -p web` で静的な SPA を出力）
- ホスティング：Vercel（`vercel.json`。SPA のため全パスを `index.html` に rewrite）

### ディレクトリ構成

```
src/
  app/          画面（Expo Router。ファイル＝画面）
    (tabs)/     ホーム・収支・資産・予算目標・設定のタブ
    quick-add.tsx  クイック入力画面（/quick-add?kind=expense&categoryId=food）
    receipt.tsx    レシート読み取り画面
  data/
    state.ts    データ操作の純粋関数（取引の保存で口座残高も更新、など）
    store.ts    localStorage への保存と画面への通知
    repo.ts     画面から呼ぶ書き込み操作
    DataProvider.tsx  画面にデータを渡す
  lib/          計算（calc）・日付・金額の書式・初期データ・バックアップの形式
    receipt.ts  レシートの文字から合計額・日付・店名・カテゴリを取り出す
    ocr.ts      画像の文字認識（Tesseract.js をブラウザ内で実行）
  ui/           共通コンポーネント・取引入力フォーム・バックアップ・ダイアログ・日付入力
scripts/
  copy-ocr-assets.mjs  文字認識のエンジンと日本語モデルを node_modules から public/ocr にコピー（ビルド時に自動実行）
```

### 保存データの形式

localStorage のキー `managemoney:v1` に次の JSON を保存しています（バックアップファイルは `{ app: "managemoney", version: 1, exportedAt, data }` で、`data` が同じ形です）。

| キー | 内容 |
|---|---|
| `accounts` | 口座（名前・種類・残高・並び順・アーカイブ） |
| `categories` | 収入／支出カテゴリ（名前・アイコン・色） |
| `transactions` | 取引（種類・金額・カテゴリ・口座・振替先・日付・メモ） |
| `budgets` | 月の予算（ID はカテゴリID、全体は `total`） |
| `goals` | 目標（目標額・期日・進捗に使う口座 or 手入力額） |
| `settings` | クイック入力に出すカテゴリ、入力時のデフォルト口座 |
